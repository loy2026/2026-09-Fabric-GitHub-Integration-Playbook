Reference material#

Technical assertions in this playbook were verified against the vendors' current product documentation at the time of writing. The following are the authoritative sources; consult them rather than this document when a behaviour must be confirmed.

  • Microsoft Learn — What is Microsoft Fabric Git integration? (overview and the supported-item inventory)
  • Microsoft Learn — Basic concepts in Git integration (permissions, connect and sync, folders, source control pane, considerations and limitations)
  • Microsoft Learn — Get started with Git integration (prerequisites, connection, commit, update, the Contributor branch-change setting)
  • Microsoft Learn — Development process using branch workspace (branch-out, selective branching, switch branch, limitations)
  • Microsoft Learn — Configure branch workspace admin profile (preview)
  • Microsoft Learn — What is a variable library? (structure, supported consumers, limits)
  • Microsoft Learn — Git integration tenant settings and About tenant settings
  • Microsoft Learn — Roles in workspaces in Microsoft Fabric
  • GitHub Docs — About rulesets and Available rules for rulesets
  • GitHub Docs — Managing encrypted secrets for your repository and organization, and Using environments for deployment
  • GitHub Docs — Managing your personal access tokens (fine-grained tokens)
  • GitHub Docs — About code owners
  • GitHub Docs — Repository roles for an organization
Note

Re-verify before relying on a specific behaviour

Fabric Git integration and GitHub's ruleset catalogue both change frequently. Where this playbook and the current vendor documentation disagree, the vendor documentation is correct and this playbook needs updating — record the correction in the revision history.
