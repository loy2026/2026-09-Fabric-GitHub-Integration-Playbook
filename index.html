Reference playbook

Microsoft Fabric
GitHub Integration &Application Lifecycle Management

Establishing a secure, auditable and repeatable source-control practice for Microsoft Fabric workspaces using GitHub — tenant prerequisites, safe workspace connection, branching model, isolated development, access control, repository hardening, credential management and rollback.

Document type
Generalized reference playbook — vendor- and organization-neutral
Audience
Data platform engineering, Fabric administrators, DevOps, security and governance
Scope
Fabric Git integration with GitHub. Release promotion via deployment pipelines is referenced but documented separately.
