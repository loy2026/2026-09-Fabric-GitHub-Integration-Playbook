9Supported items and their representation in Git

Knowing what the integration covers is a planning input, not a detail. An unsupported item is not protected by any of the controls in this playbook, and its absence from the repository is silent — it simply never appears.

Caution

Verify this inventory before relying on it

Fabric's supported-item list changes frequently and many entries are in preview. The inventory below was accurate when this document was written. Check the current vendor documentation before making a design decision that depends on an item type being supported — particularly for a preview item.

9.1How items are represented in Git#

Supported items are written out as human-readable text, which is what makes review and diffing possible. Each item occupies a folder containing a .platform file plus its definition files.

Note

Real-Time Intelligence is now supported

Earlier guidance — including earlier versions of this playbook — listed Eventstream, KQL databases, KQL querysets and Real-Time dashboards as unsupported. They are now supported. If your design routed around that limitation, revisit it.
